❓ Help & User Guide

🚀 Getting Started

  1. Create an account by clicking "Create one" on the login screen.
  2. Set up your security questions carefully — they are needed to reset your password.
  3. Go to Rates and configure hourly rates for each vehicle type.
  4. Go to Settings to set your currency, receipt header, footer, and theme.
  5. Start issuing tickets via New Ticket.

🎫 Issuing a Ticket

  • Enter the vehicle number and select type.
  • Add owner/phone (optional).
  • Print the receipt for the customer.

🚪 Closing a Ticket (Exit)

  • Open Active Vehicles.
  • Click "Exit & Print" on the row — system auto-calculates fee based on duration.
  • Hand the printed receipt to the customer.

💾 Backup & Restore

  • Always download a backup before clearing data.
  • Restore is useful when moving data to a new device.

🔑 Forgot Password?

  • Click "Forgot password" on the login screen.
  • Enter your username to load the security questions set during signup.
  • Answer them correctly and set a new password.

🌐 Language & Currency

  • Use the language dropdown in the header to switch UI language.
  • Choose from 21 currency presets or enter a custom symbol in Settings.

💡 Tips

  • Data is stored in your browser's localStorage — keep regular backups!
  • The app works fully offline once loaded.
  • You can host it on GitHub Pages or simply open index.html locally.
